PhD Tracker V1
============================

最简单的使用方法：
1. 解压 phd-tracker-v1.zip
2. 双击 index.html
3. 浏览器打开后即可使用

重要说明：
- 数据默认保存在你当前浏览器的 localStorage 中。
- 换浏览器、清除浏览器数据或换电脑，数据不会自动同步。
- 建议定期进入“设置” -> “导出全部数据”进行备份。

部署到 GitHub Pages：
1. 登录 GitHub，创建一个新仓库，例如 phd-tracker
2. 上传 index.html、style.css、app.js、manifest.json
3. 打开仓库 Settings -> Pages
4. Source 选择 Deploy from a branch
5. Branch 选择 main，文件夹选择 /(root)，保存
6. 等待 GitHub 生成公开网址

V1 已包含：
- 时间段记录
- 分类
- 自由标签
- 日历
- 每日备忘
- 独立备忘录
- 7/30/90/365 天和自定义范围统计
- 类别统计
- 标签统计
- 每日趋势
- 编辑/删除记录
- JSON 数据导入/导出
- 自定义类别
- 响应式手机布局
