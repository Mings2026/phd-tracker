PhD Tracker V1.1
============================

本版本新增
--------
1. 实时计时器
   - 填写任务名称、类别、项目/论文、标签后直接开始计时
   - 支持暂停、继续、停止并保存、放弃
   - 停止后自动写入当天时间记录
   - 正在运行的计时状态会保存在浏览器中，刷新页面后仍能继续显示

2. GitHub 风格年度科研热力图
   - 位于“统计”页面
   - 只统计类别为“科研”的记录
   - 按每天科研投入时长显示深浅
   - 显示全年科研总时长、科研活跃天数、最长连续投入天数
   - 可切换查看往年

3. 项目 / 论文维度统计
   - 每条时间记录可以归属到一个项目或论文
   - 例如：Paper 1、Paper 2、歧管微通道项目、毕业论文
   - “统计”页面会按项目/论文汇总投入时长、记录数和占比
   - “设置”页面可以管理项目/论文名称

与 V1 数据兼容
--------------
V1.1 继续使用原来的浏览器本地数据存储键，因此在同一个 GitHub Pages 网站、同一个浏览器中直接覆盖网页文件后，原有 V1 时间记录会继续保留。

尽管如此，升级前仍强烈建议：
设置 -> 导出全部数据
先保存一份 JSON 备份。

更新现有 GitHub Pages 网站
------------------------
1. 先打开当前 PhD Tracker 网站，进入“设置” -> “导出全部数据”备份。
2. 打开 GitHub 的 phd-tracker 仓库首页。
3. 将本压缩包解压。
4. 把以下文件上传到仓库根目录，并覆盖旧版本：
   - index.html
   - app.js
   - style.css
   - manifest.json
   - README.txt
5. Commit changes。
6. GitHub Pages 会自动重新部署；网站网址保持不变。
7. 等待约几十秒到几分钟后刷新网站。如果仍显示旧版，可用 Ctrl+F5 强制刷新。

V1.1 原有功能
------------
- 时间段记录
- 分类
- 自由标签
- 日历
- 每日备忘
- 独立备忘录
- 7/30/90/365 天和自定义范围统计
- 类别统计
- 标签统计
- 每日趋势
- 编辑/删除记录
- JSON 数据导入/导出
- 自定义类别
- 响应式手机布局

数据说明
--------
数据仍默认保存在当前浏览器 localStorage 中。
不同电脑或浏览器之间目前不会自动同步。
请定期导出备份。
